# 案例 04 · 夏日午后

**22 秒 / 6 镜 / 1280×720 / 24fps · 日系电影感美学短片**

主题：一个充满夏日氛围、宁静、文艺的剪辑短片，通过一系列富有诗意的静态与动态画面，营造出安详、舒适的生活美学感受。

## 风格定位

**日系电影感美学风格**：温暖、柔和、诗意。

- **整体色调**：低饱和度暖色调为主，绿色和棕色调偏多，营造清新、自然、复古的氛围
- **光线**：自然光，尤其是阳光透过树叶洒下的光斑和阴影，营造斑驳、柔和的光影效果
- **质感**：画面细腻，纹理清晰，有胶片电影的颗粒感，质感温润
- **构图**：多采用景深较浅的特写或近景，突出主体；也包含广角俯视镜头，展现场景全貌

## 主体与场景

| 主体 | 描述 |
|---|---|
| 青苹果 | 一颗完整的、新鲜的青苹果，表皮有水珠，漂浮在清澈水面上 |
| 女孩 | 长发，身穿白色吊带裙，静静地坐在窗边看书，姿态放松而优雅 |

| 场景 | 描述 |
|---|---|
| 窗边 | 一扇古朴的木质窗户，窗外是茂密的绿色植物，窗台上有木质桌面，放置玻璃鱼缸（两条金鱼） |

## 其他固定要素

| 要素 | 描述 |
|---|---|
| 风铃 | 由多根银色金属管和木质部分组成，悬挂在屋檐下，随风轻轻摇晃 |
| 麻雀 | 一只棕色羽毛的麻雀，体型小巧，停留在树枝上 |
| 金鱼缸 | 透明的球形玻璃鱼缸，水清澈透明，里面有两条橙色的小金鱼 |

## 6 镜分镜表

| # | 时长 | 镜头 | 画面内容 |
|---|---|---|---|
| 01 | 2s | 特写 · 青苹果 | 青苹果漂浮在清澈水面上，鹅卵石水底，水珠停留在苹果表皮，水面有波纹 |
| 02 | 2s | 中景 · 风铃 | 风铃悬挂在古朴木质屋檐下，银色金属管，背景是茂密绿色植物和阳光 |

| 04 | 4s | 中景 · 窗边 | 前景金鱼缸（两条橙色金鱼游动），背景女孩坐在窗边安静看书，窗外绿色植物 |
| 05 | 4s | 近景 · 女孩侧脸 | 女孩侧脸和背部近景，安静地翻书，暖光从窗外洒入 |
| 06 | 3s | 俯视全景 | 从高处俯瞰窗户、老旧瓦片屋顶和周围绿色植物，女孩在窗户中显得小而安静 |

## 三条关键设计

1. **自然声音先行** —— 流水声、鸟鸣、风铃、翻书声、风声，所有音效都是环境自然声，BGM 只做极轻的钢琴垫底，不抢戏。

2. **静与动的节奏** —— 前两镜全静（苹果、风铃），第三镜一个小动态（麻雀飞走），后三镜回到人物的安静状态。动的只有麻雀这一个"事件"，其余全部是舒缓的呼吸感。

3. **光斑作为视觉母题** —— 阳光透过树叶洒下的斑驳光影贯穿所有镜头：水面光斑、风铃周围光斑、女孩脸上的光斑、屋顶植物的光斑。光影本身就是叙事。
