# 案例 05 · 阿马尔菲柠檬海岸

**43 秒 / 24 镜 / 1280×720 / 24fps · 地中海夏日度假风旅行 vlog**

> 一段剪辑精良、节奏轻快、充满异域风情的意大利旅行 vlog。快速镜头切换把阿马尔菲海岸的绝美景色（波西塔诺小镇、湛蓝海水、悬崖建筑）与当地人文风情（露天市场、特色美食、休闲人群）结合，营造阳光明媚、惬意悠闲的度假氛围。

| 项目 | 参数 |
| --- | --- |
| 时长 / 画幅 / 帧率 | 43.00 s / 1280×720（16:9） / 24 fps |
| 编码 / 体积 | H.264 + AAC 立体声 / 约 18 MB |
| 镜头数 | 24（单镜 1–3 秒，硬切为主） |
| 单镜时长 | `1,2,2,2,2,2,2,1,2,1,2,2,2,2,2,1,1,1,2,3,2,2,2,2` |
| 色调 | 高饱和度高亮度：明亮蓝 / 鲜艳柠檬黄 / 温暖橙 |
| 生成方式 | WorkBuddy `ImageGen` 首帧 24 张 + `VideoGen` 图生视频 14 段 + 10 镜 Ken Burns 微动 |
| 拼装 | `python make_final.py`（ffmpeg 硬切 + 统一调色 + 合成 BGM，不叠加任何文字） |

## 风格定位：地中海夏日度假风

- **整体色调**：高饱和度、高亮度，以明亮的蓝（天空与海水）、鲜艳的黄（柠檬与建筑）和温暖的橙色为主，色彩对比强烈。
- **光线**：阳光充足，多为晴朗白天，光线自然明亮，部分镜头有强烈逆光效果，制造光斑和耀眼的光晕。
- **画质**：画面干净、细节锐利、无噪点，偏暖色调滤镜、饱和度提升，营造梦幻般的油画质感。
- **构图**：多个航拍 / 高位俯视展示宏大海岸线与错落建筑群；特写聚焦手捧柠檬、美食、人物表情；少量门框 / 拱门形成画中画对称构图。
- **主体**：亚洲年轻女性旅行博主，长发及肩、身材苗条、笑容甜美；白色/淡黄色连衣裙、草编宽檐帽、草编手提包、白色运动鞋或凉鞋。
- **柠檬母题**：个头巨大、形状饱满、表皮厚实、鲜亮黄色带少许青色点缀，出现在市场摊位、柠檬冰沙、手持道具中。

## 三个核心场景

| 场景 | 要点 |
| --- | --- |
| 波西塔诺小镇 Positano | 依山而建、面朝大海；密集彩色房屋层叠于悬崖，白/黄/粉/橙为主、红瓦屋顶；狭窄蜿蜒台阶石路；湛蓝地中海上停泊游艇；三角梅与葱郁植被；标志性圆顶教堂 |
| 阿马尔菲大教堂 Duomo di Amalfi | 拜占庭、哥特与巴洛克混合的罗马式建筑，主立面色彩斑斓，台阶高耸，位于小镇中心；周边露天咖啡馆、小商店与来往游客 |
| 市场与小巷 | 木架藤编摊位堆满柠檬、橘子、香蕉、樱桃、辣椒、大蒜；小巷狭窄曲折，彩色房屋外墙有壁画与手工艺品 |

## 其他固定要素

- **转场**：快切（不同场景快速切换）、跳切（同场景连续动作剪成不连续镜头）、缩放（快速拉近/拉远强调主体）。
- **叠加字幕**：无。成片不叠加任何 ID / 水印 / 字幕文字，保持画面纯净。
- **音乐**：轻柔舒缓的钢琴旋律，开头异域风情、中段节奏加快、观景段渐缓、全景段更具气势、结尾逐渐淡出；另垫极轻的海浪底噪。

## 三条关键设计

1. **常量词块锁定** —— 每条生图提示词 = `风格词块`（高饱和 / 明亮蓝黄橙 / 晴朗正午逆光 / 暖调油画 / 4K 干净无噪点 / clean image, no CGI）+ `人物词块`（亚洲年轻女性、长发及肩、苗条、甜美笑容、CLEAN BEAUTY face、服装配件）+ `场景构图词块`。人物词块 24 镜一字不改，避免跨镜换脸。
2. **柠檬黄作为色彩母题** —— 镜头 01/04/10/14/16 用高饱和柠檬黄做视觉锚点，把分散的海景、街景、人物镜头串成一条线；拼装阶段统一 `eq=saturation=1.10:contrast=1.03:brightness=0.01` 收口色调。
3. **节奏曲线由分镜表控制，不由模型控制** —— 每段素材都是 5 秒，模型不理解「1 秒快切」；生成阶段只管画面，拼装阶段按 `DUR` 逐段 trim，用 1 秒镜（01/08/10/16/17/18）制造快切密度，3 秒镜（20）做全景释放，末镜淡出收尾。

## 实测踩坑（本案例新增）

| # | 问题 | 现象 | 解法 |
| --- | --- | --- | --- |
| 8 | 模型强制带音轨 | 传 `enable_audio=false` 给 `minimax-video-h3`，直接报 `always generates audio and cannot disable it` | 生成阶段不传该参数，拼装阶段对每段 `-an` 统一去轨，音轨整体后置合成（结论与踩坑 #6 一致，但报错点不同） |
| 9 | 右下角模型水印 | `ImageGen` 首帧右下角带「AI生成」字样，成片里会跟着出现 | 统一裁 16:9 时 `crop=iw:iw*9/16:0:(ih-iw*9/16)/2`，上下各裁约 8%，顺带把底部水印裁掉，同时把 3:2 素材规范成 16:9 |
| 10 | 24 镜全量图生视频性价比低 | 单段图生视频约 2–3 分钟，且脚本里 10 镜明确写「无明显运动，固定机位」 | 只对 14 个有画面内运动/镜头运动的镜头出视频，其余 10 镜用首帧 Ken Burns 微动（in / up / left），`make_final.py` 自动按 `videos/` 是否存在补位 |
| 11 | 并行生图文件名冲突 | 同批 3 张落到同一目录，文件名只由 prompt 前缀派生 | 单批 ≤3 张、每张用不同前置短语、按返回 `localPath` 精确改名为 `shotNN.png` |
| 12 | 图生视频画幅由首帧决定 | 传 `aspect_ratio` 会报错（案例 01 已记录） | 不传，交由首帧 + 拼装阶段统一裁切 |
| 13 | 推送通道被代理拦截 | `git clone` / `git push` 走 HTTPS 时 CONNECT 隧道返回 502，`api.github.com` 的 GET/POST 正常 | 用 GitHub Git Data API 单 commit 提交（blobs → tree → commit → PATCH ref）。**本案例视频因此以普通 blob 入仓，未走 LFS**，`git clone` 后无需 `git lfs pull` 即可播放；若需统一到 LFS，可执行 `git lfs migrate import --include="*.mp4"` |

## 复现

```bash
git clone https://github.com/kedamano/AI_Video_cases.git
cd AI_Video_cases/amalfi-coast-vlog
pip install pillow numpy imageio-ffmpeg   # 或系统 PATH 里有 ffmpeg
python make_final.py
# → 阿马尔菲海岸_成片.mp4（43.00s）
```

`make_final.py` 会读取 `frames/` 与 `videos/`；缺哪一段视频就自动用对应首帧做 Ken Burns 微动，所以只保留首帧也能出片。
